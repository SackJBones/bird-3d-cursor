
We want bird to exist
Bird is a 3d interaction technique that moves a cursor in midair based on hand pose

Conceptually, it's based on fitting a sphere to the points of the hand that are tracked by VR. So the knuckles, the finger joints, tips, and then that sphere fit--like a larger sphere means the hand is more open and it moves farther away, and with a smaller sphere, the cursor moves closer to the hand, so that a closer-fitting position is more direct and concise. The one thing that isn't tracked on the hand is the pointer finger, which is reserved for clicking, which is defined as penetrating deeply enough into the sphere.
So like, having it go more than some threshold distance inward toward the center of the sphere.
